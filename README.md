# ניהול משימות - רכז שכבה

שלד ראשוני. מנוע פענוח מבוסס-חוקים (בלי AI), בסיס נתונים SQLite מקומית שמתחלף
ל-Supabase (Postgres) בפרודקשן בלי לשנות קוד.

## הרצה מקומית

```bash
pip install -r requirements.txt
streamlit run app.py
```

האפליקציה תיפתח בדפדפן בכתובת `http://localhost:8501`.
בהרצה מקומית נוצר קובץ `tasks.db` (SQLite) באותה תיקייה - כל הנתונים נשמרים בו.

## פריסה חינמית (Streamlit Community Cloud + Supabase)

1. **להעלות את הקוד ל-GitHub** - צור repository חדש (יכול להיות פרטי) והעלה את
   כל הקבצים בתיקייה הזו.

2. **להקים בסיס נתונים ב-Supabase** (חינמי):
   - הרשמה ב-supabase.com, יצירת פרויקט חדש.
   - בהגדרות הפרויקט → Database → Connection string, העתק את כתובת ה-URI
     (מתחילה ב-`postgresql://`).

3. **לפרוס ב-Streamlit Community Cloud** (חינמי):
   - הרשמה ב-share.streamlit.io עם חשבון GitHub.
   - "New app" → בחר את ה-repository → קובץ ראשי: `app.py`.
   - לפני ההפעלה, בהגדרות ה-App → Secrets, הוסף:
     ```
     DATABASE_URL = "postgresql://...הכתובת מ-Supabase..."
     ```
   - האפליקציה תשתמש אוטומטית ב-Supabase במקום SQLite המקומי.

## מבנה הקבצים

- `db.py` - הגדרת טבלאות (משימות + חוקים) וחיבור לבסיס הנתונים.
- `parser.py` - מנוע החוקים: זיהוי דדליין, דחיפות, ולמי מיועד מתוך טקסט חופשי.
- `app.py` - ממשק Streamlit: הוספת משימה, תור בדיקה, כל המשימות, תבניות וחוקים.

## מה עובד כרגע (v1)

- קלט חופשי בעברית → פענוח אוטומטי (כותרת, למי מיועד, דדליין, דחוף).
- כל משימה חדשה נכנסת עם סטטוס "ממתין לאישור" ולא זזה משם עד שתאשר.
- מסך "תור בדיקה" - עריכה ואישור, מעבר ל"לפעולה"/"למעקב"/"סגורה".
- מסך "כל המשימות" - כרגע פתוח לכולם (כפי שביקשת לשלב הראשון), עם סינון לפי סטטוס.
- מסך "תבניות וחוקים" - הוספת כללי זיהוי קבועים (בעיקר למיפוי "למי מיועד").

## מה עוד לא נבנה (לשלבים הבאים)

- ייצוא הודעת ווטסאפ (למשימה בודדת / סיכום שבועי).
- כניסת מחנכים עם קוד זיהוי (שלב ב').
- שיפור זיהוי "כותרת" (כרגע רק מסנן ביטויי תאריך/דחיפות מהטקסט המקורי).
